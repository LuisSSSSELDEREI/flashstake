# FlashStake

Мод для Minecraft: апгрейд предметов, маркет, кейсы, дабл и арена.

Открыть меню в игре — клавиша **U**.

## Скачать

## Как поставить

1. Нужен **Forge** той же версии Minecraft.
2. Положи скачанный `.jar` в папку `mods`.
3. Запусти игру.
